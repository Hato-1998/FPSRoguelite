컨설턴트 토론을 수행한다. **반드시 먼저 [`Docs/ConsultLoop.md`](Docs/ConsultLoop.md) 전체를 읽고 그 프로토콜대로** 진행하라. (그 문서가 SSOT — 아래는 요약일 뿐.)

토론 주제: **$ARGUMENTS**
- 인자가 비어 있으면, 먼저 무엇을 토론할지 사용자에게 물어본 뒤 진행한다.

수행 순서 (ConsultLoop §3):
0. **범위 게이트 (ConsultLoop §0-1)** — `Docs/SSOT/Workflow.md` §6-5-2 트리거 `T1~T5`로 판정. 하나라도 걸리면 **IN**(Codex 호출). 하나도 안 걸리면 **OUT** → Codex를 부르지 않고 Claude 단독 자문으로 진행하고, **그 사실을 보고에 1줄로 밝힌다**(조용히 생략 금지). 애매하면 IN.
1. **R0 범위설정** — `Game.md`·PM 보드(§6-9) + 주제 관련 `Docs/SSOT/*.md`와 관련 소스/콘텐츠를 읽어 **사실 기반**을 잡고, 핵심 쟁점 2~4개로 의제를 프레이밍한다(추측 금지).
2. **R1~ 토론 루프** — 너는 **안건 소유자**다. 라운드마다: ① 안건 작성 → ② 프롬프트 파일에 (의제/합의/쟁점 요약 + 이번 라운드 안건 + 구체 질문 2~4개)를 적고 — **역할 프라이머는 쓰지 마라, 래퍼가 `Docs/CodexRedTeamPersona.md`를 자동으로 앞에 붙인다** → ③ `Scripts/consult-codex.ps1 -PromptFile <file> -Title <슬러그>` 로 **웹/앱 적대 레드팀(Codex)** 의 공격을 받는다 → ④ 판독·반박·조정 후 다음 라운드. **새 실질 논점이 안 나올 때까지** 반복. 5분 내 무출력이면 종료·스킵.
3. **수렴 정리** — (a)합의 / (b)미해결 쟁점 / (c)사용자 결정 필요 로 분류.
4. **종료 (ConsultLoop §3-1)** — **최종 결정권은 너에게 있다.** 언제든 끝낼 수 있되, ⓐ `종료 사유` 1줄 + ⓑ **기각 원장**(기각한 지적 전부 + 각각의 근거 = 제1원리 조항 / 코드 인용 / 실측치)을 남겨야 성립한다. 근거를 못 대면 기각이 아니라 (b)쟁점으로 내린다. `[가설]` 태그 지적은 기각 말고 **검증 항목**으로 옮긴다.
5. **산출** — ConsultLoop §5 템플릿으로 `Docs/Review/<yyyyMMdd>-<슬러그>.md` 저장 + 사용자에겐 **압축 요약**(합의/기각/쟁점/결정필요/액션)을 채팅 보고.

가드레일 (ConsultLoop §6): **자문 전용 — 코드/에셋 변경 금지.** 채택 설계는 별도 단계에서 해당 `Docs/SSOT/` 파일을 먼저 갱신. **너의 결정권은 토론을 끝낼 권한이지 실행 권한이 아니다 — HIGH_RISK는 여전히 사용자 승인 뒤.** 양쪽 다 장르 정체성(`Game.md` §1, **Hero Shooter 아님**)·제1원리에 구속. Codex 미설치/미인증이면 `npm install -g @openai/codex` + `codex login` 안내.
