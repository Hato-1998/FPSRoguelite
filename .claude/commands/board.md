Notion PM 보드 작업을 **`pm-board` 서브에이전트에 위임**한다. 직접 Notion 도구를 부르지 말 것 — 조회 결과가 이 세션 컨텍스트에 쌓이고, 호출 예산 관리 주체가 둘로 갈린다.

`Agent` 도구로 `subagent_type="pm-board"` 를 띄우고, 인자 `$ARGUMENTS` 를 그대로 넘긴다.

- `클레임 <작업>` — §6-9 (3) 착수 전 조사
- `마감 <결과·커밋>` — §6-9 (4) 갱신
- `감사` — 보드↔git 드리프트 검사 (D1~D8)
- (인자 없음) — 현황 요약 + 다음 착수 후보

에이전트가 돌려주면:

1. **`## 크리티컬` 을 먼저 본다.** 미착수 크리티컬이 있으면 지금 요청과 무관해도 사용자에게 **먼저 보고**한다(§6-9 (3)-2).
2. **`## 선행·충돌` 을 읽고 착수 여부를 판정한다.** 에이전트의 `## 권고` 는 권고지 판정이 아니다 — 선행 미완료나 경로 충돌이 있으면 기본값은 **대기**이고, 진행하려면 사용자에게 보고한다.
2-1. **마일스톤 개시 규칙을 확인한다**(§6-9 (8) · `Roadmap.md` §7-6 (4)). 집으려는 행보다 **앞선 마일스톤에 활성 행이 남아 있으면 기본값은 그쪽 먼저**다. 당겨 쓸 수 있는 예외는 셋뿐 — ①`크리티컬` ②현행 빌드를 깨는 회귀·크래시 ③뒤 슬라이스의 판정을 오염시키는 결함. 예외로 당기면 **행 로그에 사유를 남긴다**. 보고에 `마일스톤` 칸이 비어 있으면 그건 **미배정**이지 "아무 때나"가 아니다 — 사용자에게 배정을 물어라.
3. **`## 실행 필요(메인)` 의 도구 호출을 실행한다.** 에이전트는 기존 행의 속성을 바꿀 권한이 없다(로그 append·신규 행 생성만) — 상태·담당·브랜치·우선순위·완료커밋 변경은 여기서 네가 한다.
4. 클레임을 실행했으면 **행을 재조회해 `담당`이 나인지 확인한다**(§6-9 (3)-7 — Notion엔 트랜잭션이 없다). 다른 세션이면 양보한다.
5. `## 소비한 SQL 호출` 이 2회를 넘었으면 이후 조회는 표적 조회만 쓰도록 지시한다(무료 플랜 한도).

에이전트가 "Notion MCP 미연결"을 보고하면 **작업을 시작하지 말고** 사용자에게 연결을 요청한 뒤 대기한다(§6-9 (1) 하드 게이트). 유일한 예외 = 사용자가 명시적으로 "보드 없이 진행"을 지시한 경우.
