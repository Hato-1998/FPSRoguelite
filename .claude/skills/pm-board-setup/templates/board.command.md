PM 보드 작업의 창구. 절차의 SSOT는 `{{PROTOCOL_DOC}}` 이고 이 파일은 **라우팅만** 한다 — 절차를 여기 복제하지 않는다(2026-08-11 실사고: 복제본이 신설 규칙의 반대를 지시했다). **프로토콜 (7) 「누가 무엇을 하는가」 표에 따라 갈래가 둘이다** — 클레임·현황은 메인 세션 직접, 마감·감사는 `pm-board` 에이전트 위임.

인자: `$ARGUMENTS`

## 갈래 1 — `클레임 <작업>` · (인자 없음) = **메인 세션이 직접 실행**

에이전트를 띄우지 말 것. 작업집합 조회가 2행이라 태울 값이 없다(프로토콜 (7) 개정 2026-09-09).

1. **절차를 잘라 읽는다**(전문을 읽지 않는다):
   ```bash
   sed -n '/^## (3) 작업 전 절차/,/^## (4) 작업 후/p' {{PROTOCOL_DOC}}
   ```
   ⚠️ 헤더를 `(3)` 까지만 줄이지 말 것 — 지금은 {{PROTOCOL_DOC}} 안에 `(3)`이 하나뿐이라 문제없지만, 이 프로토콜 문서를 다른 문서에 합치는 순간 절 번호가 겹쳐 sed 가 엉뚱한 절을 잡을 수 있다(원형 FPSRoguelite 에서는 같은 파일 안에 `(3)` 헤더가 둘이라 실제로 이 함정을 겪었다).
2. **작업집합을 확보한다**((2) ①) — `.claude/board-snapshot.md` 가 있으면 그 파일을 읽는다(네트워크 0 — 프로토콜 (10)). 없으면 SQL을 1회 부른다.
3. 읽어 온 (3) 절차를 밟는다. 집을 행은 (2) ②로 표적 조회한다(백로그 전체를 훑지 않는다). 행이 없으면 `notion-create-pages` 로 만든다 — 상태=대기, `크기`<!-- IF:MILESTONE -->·`마일스톤`<!-- /IF:MILESTONE --><!-- IF:GATE -->·`{{GATE_COL}}`<!-- /IF:GATE --> 포함.<!-- IF:MILESTONE --> **마일스톤이 불분명하면 비워 두고 사용자에게 보고**(임의 배정 금지).<!-- /IF:MILESTONE -->
4. **클레임** = `notion-update-page` / `update_properties` — 상태=진행중, `담당`=`<클론>@<브랜치> · MMDD-키워드`, `브랜치`.
5. **경합 재확인** — 클레임 직후 그 행을 재조회해 `담당`이 나인지 확인한다(프로토콜 (3)-7, Notion엔 트랜잭션이 없다). ⚠️ **스냅샷으로 대신할 수 없다** — 내 쓰기 *이후*의 상태를 봐야 한다. 다른 세션이면 양보한다.

**인자가 없으면**: 스냅샷(또는 (2) ① SQL)으로 현황을 요약한다. "다음에 뭘 하지"면 (2) ③ 대기열 조회를 쓴다(<!-- IF:MILESTONE -->현재 마일스톤 스코프 + <!-- /IF:MILESTONE -->`LIMIT`로 제한) — 전체 대기열을 끌어오지 않는다.

## 갈래 2 — `마감 <결과·커밋>` · `감사` = **`pm-board` 에이전트에 위임**

`Agent` 도구로 `subagent_type="pm-board"`, `$ARGUMENTS` 를 그대로 넘긴다. 둘 다 다단계라 메인 컨텍스트를 아끼는 값이 실제로 있다.

에이전트가 돌려주면:

1. **`## 크리티컬` 을 먼저 본다.** 미착수 크리티컬이 있으면 지금 요청과 무관해도 사용자에게 **먼저 보고**한다(프로토콜 (3)-2).
2. **`## 실행 필요(메인)` 의 도구 호출을 실행한다.** 에이전트는 기존 행의 속성을 바꿀 권한이 없다(로그 append·신규 행 생성만) — 상태·담당·브랜치·우선순위·완료커밋 변경은 여기서 네가 한다.
3. `## 소비한 SQL 호출` 이 2회를 넘었으면 이후 조회는 표적 조회만 쓰도록 지시한다(무료 플랜 한도).

## 공통 — 착수 판정은 언제나 메인이 한다

- **선행·충돌**: 선행작업이 미완료거나 `주요경로`가 진행중 행과 겹치면 기본값은 **대기**다. 진행하려면 사용자에게 보고한다. `크기`가 `XL`이면 클레임하지 않고 분할부터.
<!-- IF:MILESTONE -->
- **마일스톤 개시 규칙**(프로토콜 (8)): 집으려는 행보다 **앞선 마일스톤에 활성 행이 남아 있으면 기본값은 그쪽 먼저**다. 당겨 쓸 수 있는 예외는 셋뿐 — ①`크리티컬` ②현행 빌드를 깨는 회귀·크래시 ③뒤 묶음의 판정을 오염시키는 결함. 예외로 당기면 **행 로그에 사유를 남긴다**. `마일스톤` 칸이 비어 있으면 그건 **미배정**이지 "아무 때나"가 아니다 — 사용자에게 배정을 물어라.
<!-- /IF:MILESTONE -->
- **Notion MCP 미연결**이면 **작업을 시작하지 말고** 사용자에게 연결을 요청한 뒤 대기한다(프로토콜 (1) 하드 게이트). 유일한 예외 = 사용자가 명시적으로 "보드 없이 진행"을 지시한 경우.
  ⚠️ **스냅샷 파일이 있어도 이 게이트는 풀리지 않는다** — 클레임은 *쓰기*라 MCP가 필요하다. 스냅샷은 읽기만 대신한다.
