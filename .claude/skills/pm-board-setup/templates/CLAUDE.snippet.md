## 핸드오프 = PM 보드
- 작업 전 보드 클레임(조회→크리티컬 확인→선행·병렬충돌 검사→담당 기입), 단계 완료·세션 중단 전 보드 행 갱신(상태·로그·인계 컨텍스트).
- **보드 I/O 실행 주체 = `/board`(`pm-board` 에이전트)** — Notion 도구를 메인 세션이 직접 부르지 말 것(컨텍스트·SQL 한도). 에이전트는 로그 append·신규 행만 **추가**하고, 상태·담당·우선순위 갱신은 메인 세션이 실행한다.
- 우선순위 5단계: **크리티컬=사용자 전용**(에이전트 부여·강등 금지) / 하이·미듐·로우=담당 판단 / 백로그=개선점.
