# 아키텍처 결정 기록 (ADR)

구조 결정과 **그 이유, 기각된 안, 미해소 반론**을 남기는 곳이다.
결론만 적힌 문서는 몇 주 뒤에 같은 논의를 처음부터 반복하게 만든다. 토론 과정을 보존하는 것이 이 문서들의 절반이다.

## 규칙

- 파일명은 `NNNN-kebab-case-title.md`. 번호는 재사용하지 않는다.
- 결정이 뒤집혀도 **기존 문서를 고치거나 지우지 않는다.** 상태를 `대체됨(→ NNNN)`으로 바꾸고, 새 번호로 새 문서를 만들어 서로 링크한다.
- `저렴` 등급(나중에 바꿔도 국소 수정으로 끝나는) 결정은 굳이 기록하지 않는다. 전부 남기면 인덱스가 신호를 잃는다.
- 작성 방법론 = 스킬 `architecture-review`.
