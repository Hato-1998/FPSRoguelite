# 0008. 부양 적 추적 = 도달성 기반 모드 전환 (플로우 + 3D 시크)

- 상태: 대체됨(→ [0009](0009-hover-swarm-local-3d-flow-window.md))
- 날짜: 2026-08-14 (대체 2026-08-14 — PIE에서 전역 일제 상승·점프 동조 출렁임 관측, 0009 맥락 참조)
- 되돌리기 비용: 비쌈

## 맥락

프로토 판정 중 사용자가 인게임에서 발견: 플레이어가 단차(도시 맵 고가 보도) 위에 서면
적이 **아래에서 XY만 쫓고 올라오지 않는다**. 원인은 버그가 아니라 현 구조의 정의된 폴백 —
플로우필드는 걸을 수 있는 면 그래프라 45cm 초과 단차로 연결이 안 구워진 단상은 BFS 도달
불가 성분이고, 그때 이동 패스는 XY 직선 추적 폴백으로 넘어가며, 부양 v2의 Z는 "내 발밑
지형 + 부양 오프셋"뿐이라 플레이어 Z를 전혀 참조하지 않는다.

전 몬스터가 부양+원거리로 확정된 상태(f5b0a78d)라, 사용자가 "지형을 무시하고 플레이어를
쫓되 공격 방향만 고려"하는 전면 3D 추적을 제안 → 본 논의로 구조를 확정했다.

## 목표와 비목표

- 목표:
  - 플레이어가 어디 있든 적 스웜의 압박이 성립한다(도달 불가 지형에서 잉여화 금지).
  - 플레이어 Z가 적의 이동·공격 참조값이 된다.
  - 적이 빌딩·지붕을 **타 넘는 것은 허용**한다.
  - 구조적 엄폐는 보존한다(무제한 상공 사격 금지 — 적 고도는 플레이어 상대 밴드에 묶임).
  - 공중 구름화(모든 적이 같은 고도 사격 구체화)는 아키타입별 고도·공격 형태 데이터로 막는다.
- 비목표:
  - 근접 적 재도입 없음 — "근접처럼 보이는 적"도 초단사거리 원거리로 만든다.
  - 건물 위를 목적 없이 도는 잉여 몬스터 허용 안 함(금지 조건).
  - 전면 자유 비행(지형 완전 무시) 아님 — 기각안 A 참조.
- 규모 상한: 기존 유지(동시 200~300, 캡 500). 이 경로에 씬쿼리 추가 0.

## 불변식

1. 3D 시크 모드는 **"플로우 도달 불가" 또는 "비공격 정체(시간 T·최소 이동거리 D 미달)"일
   때만** 열린다. 평시 XY 라우팅의 단일 소스는 플로우필드다. (T·D·고도 밴드·비행 실링 =
   전부 아키타입 데이터)
2. 수직 통합기는 하나 — 부양 v2 스프링(FMath::SpringDamper). 모드가 바뀌어도 Z 동역학
   코드는 갈라지지 않는다.
3. 어떤 적도 "추적 중 + 공격 불가" 상태로 T초 이상 머물지 않는다(잉여 금지). 실행 수단 =
   정체 감지 트리거. 같은 장애물에 대한 재상승은 이전보다 높은 목표에서 시작한다
   (요요 금지 — 에스컬레이션 단조 증가).
4. 고도·공격 형태 차이는 아키타입 데이터로만 표현한다(코드 분기 금지 — 확장성-우선 원칙).
5. 이 경로에 씬쿼리 추가 0 — 기존 이동 스윕과 플로우필드 배열 산수만 사용한다.
6. 모드 전환은 히스테리시스(최소 유지 시간)를 갖는다 — 틱 단위 펄럭임 금지.

## 검토한 대안

### 안 A — 전면 3D 자유 추적 (사용자 최초 제안)
플로우필드에서 이동을 떼고 3D 방향 + 분리 + 공격 방향만.
- 장점: 도달 불가 상황 원천 소멸, 구현 단순.
- 기각 사유(치명): 수평 장애물 처리가 사라진다 — 빌딩 뒤 플레이어에게 스웜 200이 벽면에
  밀집해 압박 0("벽에 붙어 버둥대는 덩어리"). 이를 상승 회피로 풀면 지형 전술 가치가
  통째로 소멸(맵=시각 배경). 터널 속 플레이어에겐 위에서 맴도는 잉여를 낳는다(사용자도
  동일 우려 표명). 플로우필드가 존재하는 이유(거리 우회)를 재발명해야 한다.

### 안 B — 교전 반경 게이트 수직 엔벨로프 (초기 하이브리드)
수평은 플로우 유지, 교전 반경 안에서만 부양 목표 Z를 사선 높이로 상승.
- 장점: 지형 전술 보존, v2 스프링 재사용.
- 기각 사유(사용자 지적으로 발견): **교전 밖 + 도달 불가**에서 여전히 1층 벽에 낀다 —
  거리 기준 게이트가 구멍. 게이트를 도달성 기준으로 바꾼 것이 채택안 D다.

### 안 C — 콘텐츠 수정(램프/연결 저작)
맵마다 단상을 플로우에 연결.
- 기각 사유(단독으로는): 신규 맵마다 반복 저작 부담 + 45~60cm 함정 구간 상존, 구조적
  해법이 아님. 채택안의 보조 수단으로는 유효(맵 저작 시 연결하면 플로우 모드가 더 많이
  일해 그림이 좋아진다).

## 결정

**안 D — 도달성 기반 모드 전환** (B 수정 + A 부분 흡수 + 사용자 정체 감지/상승-하강 궤적 흡수).

- **플로우 모드**(평시): 현행 그대로 — XY 플로우 + v2 지형 상대 부양. 터널·거리·계단은
  이 모드가 이미 정답을 낸다(터널 바닥은 구워진 면 → BFS가 입구 경유 경로를 냄).
- **3D 시크 모드**(불변식 1의 트리거): XY 직선 추적 + Z 목표 = 플레이어 상대 고도 밴드.
  전진 스윕이 막히면 **뚫릴 때까지 증분 상승**(상한 = 비행 실링 데이터) 후 **하강하며
  직선 추격**(사용자 제안 궤적). 하강·착지는 부양 v2 글라이드가 그대로 수행.
- **복귀**: 3D 모드 중 플로우가 살아 있는 기둥에 오면(최소 유지 시간 경과 후) 플로우
  모드로 복귀. 공격 성공도 정체 타이머를 리셋한다.

## 근거

제1원리(적 수백 = 액터당 비용 최소화)와 지형 전술을 동시에 만족하는 유일한 안이었다.
플로우필드(검증된 기존 인프라)가 평시 라우팅을 계속 담당하고, 3D 시크는 예외 상황
탈출기로만 열린다. 수직 동역학은 부양 v2 스프링을 재사용해 새 적분기가 없다. A 대비
지형 전술과 터널 침투를 보존했고, B 대비 9번 구멍(교전 밖 벽 낌)을 막았다.

트리거를 "원인 기반(플로우 0)"에 "결과 기반(비공격 정체)"을 더한 것은 사용자 제안 —
부분 연결 구석 낌·분리 교착·지오메트리 포켓 등 원인 열거가 불가능한 케이스를 전부
그물질한다. 플로우 0 = 즉시 발동(증명된 도달 불가를 기다릴 이유 없음), 정체 감지 =
나머지의 안전망으로 상호보완.

## 전환 조건

- 근접 적을 재도입하게 되면: 지상 경로 의존이 생겨 3D 시크의 적용 범위·트리거를 재검토.
- "적이 지붕을 넘는 것"이 플레이테스트에서 지형 전술을 실질 훼손한다고 판정되면:
  3D 시크의 상승 상한/트리거를 조이거나 C(콘텐츠 연결)로 무게 이동.
- 아키타입 수가 늘어 고도 밴드 데이터만으로 위협 다양성이 안 나오면: 공격 형태 쪽
  구조(장판 캐스터 등)를 별도 논의로.

## 검증 시나리오

- 정상 흐름: 플레이어가 고가 보도 위(도달 불가 성분) → 아래 적이 플로우 0 → 즉시 3D
  시크 → 벽에 막히면 증분 상승 → 뚫리면 하강 직선 추격 → 고도 밴드에서 사격.
- 실패 흐름(잉여 교착): 지붕 위 적(고립 성분) + 터널 속 플레이어 → 플로우 영원히 0 +
  사선 막힘 → 정체 감지 T초 → 하강·재착지(글라이드) → 착지 성분이 플레이어와 연결 →
  플로우 모드 복귀 → 터널 입구로 돌아 들어감. (이 규칙이 없으면 터널 지붕 위를 뱅뱅 —
  금지 조건 위반)
- 실패 흐름(요요): 지상 플레이어 + 10m 빌딩 뒤 적 — 상승 목표가 "플레이어보다 높게"
  고정이면 지붕 아래에서 같은 벽에 반복 충돌. 증분 상승(불변식 3 에스컬레이션)이 해법.

## 논의 중 제기된 반론

- "지형 무시 시 공중 구름화로 위협이 단조로워진다"(직감 등급) → 아키타입별 고도 밴드·
  공격 형태 데이터로 해소하기로(불변식 4). 실검증은 플레이테스트로.
- "교전 반경 게이트는 교전 밖 벽 낌을 못 막는다"(사용자, 유효) → 도달성 기준 게이트로
  수정, B 기각.
- "상승 목표 '플레이어보다 높게'는 고층 장애물에서 요요를 만든다"(Claude, 유효) →
  증분 상승으로 수정 채택.
- 모드 경계 펄럭임(구조적) → 히스테리시스 불변식 6으로 해소.
- 1번 관찰("계단 근처면 올라옴")의 정확한 원인(부분 연결 vs 스텝업)은 미확정 — 구현 전
  플로우 디버그 드로우 1회 확인 예정. 어느 쪽이든 채택안이 흡수한다.
